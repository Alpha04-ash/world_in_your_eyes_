# Робия • Невысказанная история ✨

Интерактивная кинематографическая веб-история, созданная с глубоким уважением, трепетом и восхищением для Робии.

---

## 🚀 Способы публикации (Деплой за 1 минуту)

Сайт полностью статичный (HTML5, Vanilla CSS, Vanilla JS, Web Audio API). Серверная часть не требуется — сайт работает мгновенно в любом браузере и на любых смартфонах.

### Вариант 1: Vercel (Рекомендуется — самый быстрый и красивый)
1. Установите CLI (если ещё не установлен):
   ```bash
   npx vercel
   ```
2. Нажмите `Enter` на все вопросы. Через 20 секунд у вас будет готовая публичная ссылка вида:
   `https://robiya.vercel.app`

### Вариант 2: Netlify (Drag & Drop без консоли)
1. Зайдите на [app.netlify.com/drop](https://app.netlify.com/drop)
2. Просто перетащите папку `robiya` мышкой в браузер.
3. Через 10 секунд сайт опубликован!

### Вариант 3: GitHub Pages
1. Создайте репозиторий на GitHub.
2. Привяжите и отправьте код:
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/robiya.git
   git branch -M main
   git push -u origin main
   ```
3. В настройках репозитория: **Settings -> Pages -> Branch: main -> Save**.
4. Сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/robiya/`.

## 📱 Особенности проекта:
- **Mobile-First & Zero-Scroll**: Идеально подогнано под экраны смартфонов (`100dvh`), контент не требует скролла.
- **100% Векторные SVG**: Все иконки стикеров, звёзд и кнопок отрисованы в чистом SVG без дешёвых эмодзи.
- **Аудио-движок**: Процедурный Web Audio API синтезирует нежные хрустальные колокольчики и аккорды без внешних MP3-файлов.
- **Социальные превью (Open Graph)**: При отправке ссылки в Telegram, WhatsApp или Instagram подтягивается красивая обложка и заголовок.
